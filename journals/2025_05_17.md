- OpenAI 发布了 [Codex](https://openai.com/index/introducing-codex/) ，一个coding Agent。背后支撑这个 Agent 的是`codex-1`模型，这个模型是基于 `o3`做 RFT 得到的。OpenAI 的 Agent 历史：基于o1 做了 Operator；基于 o3 做了 DeepResearch。从 OpenAI 的演进路线可以看出来，他们做 Agent 的思路都是基于模型的 RFT 做优化，而不是在 AI 应用层面雕花。
- 同时还有一个 Code Agent的观察：Anthropic 有一个 Claude Code，OpenAI 有一个 Codex Cli。从 Agent Tool 来看，Claude Code 提供了一些列 Tool *(grep、ls等等)*给模型使用，也在 Prompt Engineering 上花了很多功夫。但是 Codex Cli 只提供了一个 `Shell` 作为 Tool，当时第一感觉就是：“Agent 的效果十分依赖模型能力”。果不其然，OpenAI 的思路就是在模型层面发力，让一个强大的模型去使用一个强大的 Shell。
